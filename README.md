# Market Pulse · 投资日历

这是一个完全本地运行的静态网页，不需要服务器或账号。

## 使用

直接双击 `index.html` 即可打开。也可以把整个 `market-calendar` 文件夹拖到浏览器窗口。

- 月历：固定使用月历视图；可点击某一天查看详情，也可以在日历中连续滚动浏览月份。
- 筛选：按宏观数据、美联储、财报、公司事件或市场事件过滤；每个类别旁的齿轮可继续按子类勾选。财报与公司事件齿轮使用同一批关注公司名单，并显示中文简称。
- 语言：默认中文为主、保留常用英文简称；可切换为全中文显示。
- 添加事件：事件会保存在当前浏览器的本地存储中，不会上传。
- 导出 `.ics`：可导入 Apple Calendar、Google Calendar 或 Outlook。
- 来源链接：内置 BLS、Federal Reserve、BEA、Nasdaq 官方入口，日期变动时以官方页面为准。
- 时区切换：可在纽约、北京、香港、伦敦和 UTC 之间切换；有时间的事件会自动换算日期与时间。
- 未来窗口：未来 90 天会持续更新；已经发生的事件、简报和历史快照保留在本机，90 天后的远期事件暂不显示。
- 本地存储：月份工具栏内显示占用大小；“清理”只删除本机自定义事件、更新快照和偏好，内置官方示例会重新载入。

## 更新方式

以后需要新增事件时，可以直接告诉我事件名称、日期（如果已确认）、类别、时间和来源链接；我可以把它追加到网页的内置清单中。财报齿轮面板列出市值前20核心和科技热点公司的中文名单；只有拿到正式公告或可靠的预计日期才会标到月历，避免把未确认日期误当成事实。

## 手机与分享

当前版本是本地网页，数据保存在这台电脑的浏览器里；手机或别人无法直接读取这份本地存储。需要跨设备访问时，可以把同一目录部署到 GitHub Pages 或 Cloudflare Pages 的免费静态托管，再把网址发给别人；若要让自定义事件跨设备同步，还需要再接入云端存储。

## 数据口径

内置示例以 2026 年美国公开发布日程为基础，事件的源时间通常是美国东部时间（ET），显示时会按你选择的时区换算。财报标题明确写出自然年/财年及季度；未获公司正式确认的日期标为“预计”，官方已公布的活动标为“已确认”。FOMC 会议纪要的未来日期按“政策决定后三周”作预计标记，最终以美联储更新为准。每日北京时间 7:00 的更新任务只改写未来 90 天的日期、进展、预期和影响判断，不删除历史记录；没有实质变化时不会打扰你。
